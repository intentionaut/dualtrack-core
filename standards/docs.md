# Docs and messages

READMEs, help pages, emails and notices. Numbered DOC-n.

1. **First screen**: what it is, who it is for, and the first thing to do, before any detail.
2. **Runnable**: every command can be copied and run as written.
3. **Order**: steps in the order a person does them, one action per step.
4. **Plain words**: short sentences, no unexplained terms, the reader's words.
5. **Scannable**: headings say what the section holds; lists for parallel items only.
6. **Agent-friendly copy**: a person or an agent can lift any section whole.
   - Product claims in the third person ("Dualtrack does X"), never "I" or "we".
   - One-sentence plain definition first, then detail.
   - Exact commands in code blocks.
   - Headings are questions or tasks ("How do I install it?"), with stable anchors that do not change when the wording does.
   - Every public page has a plain-markdown twin and an entry in `llms.txt`.
