# Product areas

The map every agent works from: each bet, change and number belongs to one area.

You don't need to fill this in. The team drafts the map from your repo, keeps it in step as the code changes,
and shows each change in the brief: `decide areas` takes it, `decide areas no` keeps what you have. Every 90
days the brief asks you to look again, and `decide areas` marks it looked at.

Edit it any time if you'd rather. One `##` heading per area; every line under it is optional: Code (path globs
such as `src/checkout/**`), Pages (URL paths), Events (analytics event names), Success (what good looks like, in
your words) and Last reviewed (YYYY-MM-DD).
